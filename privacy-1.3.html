개인정보 처리방침

적용 버전: 온기방 1.3 · 시행일: 1.3 출시일. 1.3 TestFlight 빌드에도 이 처리 방식이 적용됩니다.

1.3은 출시 준비 중입니다. 현재 출시 버전은 1.1이며 1.1 개인정보 안내가 별도로 유지됩니다.

1. 기기에 보관하는 기록

기억의 문장과 사진, 온기 종류, 일정과 완료 상태, 선택한 기분과 하루 회고를 기기에 보관합니다. 별도 회원가입, 광고, 추적, 사용 분석은 없습니다.

2. 선택형 iCloud

iCloud를 직접 켜면 사진과 기록을 Apple CloudKit의 비공개 데이터베이스에 전송하고 같은 Apple 계정의 기기끼리 동기화합니다. 개발자는 다른 사용자의 비공개 기록을 열람하지 않습니다. Apple의 서비스와 계정 설정이 적용됩니다.

오프라인에서는 먼저 기기에 저장합니다. 동기화를 꺼도 기기와 기존 iCloud 기록은 남습니다. 계정 변경 시 동기화를 멈추며 새 계정으로 자동 전송하지 않습니다.

3. 사진과 삭제

직접 선택한 사진만 앱 내부에 JPEG 사본으로 복사합니다. 원본을 삭제해도 저장된 사본은 유지됩니다. 앱에서 기억·일정·회고를 수정하거나 삭제할 수 있으며 iCloud 사용 중에는 삭제 이력도 동기화합니다. 앱 삭제만으로 iCloud 기록이 삭제되지는 않습니다.

4. 백업

사진과 기록을 포함한 암호화되지 않은 JSON 파일을 선택한 위치에 내보냅니다. 내보낸 파일은 별도로 관리·삭제해주세요. 1.1 백업은 가져올 수 있지만 1.0 백업은 자동 변환하지 않습니다. 기기 백업에는 운영체제 설정에 따라 앱 데이터가 포함될 수 있습니다.

5. 알림과 동기화 상태

일정 알림은 권한을 허용한 기기에서만 예약합니다. 기기별 알림 설정, 전송 대기 상태, Apple 계정의 CloudKit 식별자는 동기화 관리와 계정 변경 감지를 위해 기기에 저장합니다. 내부 임의 기기 식별자는 개인 데이터베이스의 동시 수정 처리에만 사용하며 추적하지 않습니다.

6. 지원과 홈페이지

todaklife@gmail.com으로 보낸 연락처와 문의 내용은 답변을 위해 사용합니다. 개인 기록이나 사진을 보낼 필요는 없으며 문의 내용 삭제는 같은 주소로 요청해주세요.

홈페이지는 GitHub Pages의 정적 웹사이트입니다. 광고·분석·개인 기록 입력 폼이 없으며 방 체험은 예시를 사용합니다. GitHub 개인정보 정책이 호스팅 운영에 적용됩니다.
