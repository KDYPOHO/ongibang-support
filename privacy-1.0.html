이전 버전 안내

1.0 개인정보 처리방침

기존 시행일: 2026년 10월 1일. 아래 내용은 이전 버전의 정책을 보존한 것입니다.

1. 수집하는 정보

온기방 개발자는 사용자의 오늘 기록(기분·에너지·메모), 일정, 집중 기록 또는 입력 문장을 수집하지 않습니다. 광고, 분석, 추적 SDK를 사용하지 않습니다.

2. 저장 위치

오늘 기록, 일정, 완료·취소된 집중 기록과 자동화 루틴 설정은 사용자의 기기와 사용자가 선택한 개인 iCloud 비공개 데이터베이스에 저장됩니다. 진행 중인 집중 타이머와 이 기기에서 자동화 알림을 받을지는 해당 기기에만 저장됩니다. iCloud 동기화는 Apple의 서비스와 계정 설정을 따릅니다.

3. 제3자 제공

개발자는 앱 데이터를 제3자에게 판매하거나 제공하지 않습니다.

4. 내보내기와 삭제

앱의 설정에서 오늘 기록·일정·집중 기록·자동화 루틴 설정을 형식 버전 3의 JSON 파일로 내보내거나 전체 삭제할 수 있습니다. 기기별 알림 수신 여부는 내보내지 않습니다. 전체 삭제 시 예약된 로컬 알림도 함께 취소됩니다.
