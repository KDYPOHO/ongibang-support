작은 방 사용 안내

처음 들어오는 날에도 편안하게. 온기방 1.1을 사용하는 방법을 모았어요.

1.1은 새로운 기억의 방입니다. 1.0의 기록과 일정·집중 기능에 관한 문의도 아래 이메일로 보내주세요. 이전 기록을 새 백업으로 자동 변환하는 기능은 제공하지 않습니다.

01. 기억 담기

  1. 방 또는 보관함에서 ‘기억 담기’를 선택하세요.
  2. 짧은 글을 쓰거나 사진 보관함·이미지 파일에서 사진 한 장을 선택하세요. 둘 중 하나만 있어도 저장할 수 있어요.
  3. 기본값은 ‘보관만 하기’예요. 위로 흐름에서 다시 보고 싶다면 쉼·응원·연결 중 하나를 선택하세요.
  4. ‘저장’을 누르면 기억이 기기 내부에 보관돼요.

02. 필요한 온기 꺼내보기

쉬고 싶을 때는 담요, 응원이 필요할 때는 스탠드, 연결감을 느끼고 싶을 때는 머그잔을 선택하세요. 아래 온기 버튼으로도 열 수 있어요. 해당 온기를 직접 지정한 기억을 최근 저장 순으로 한 장씩 보여줘요. 기억이 없으면 새 기억을 담거나 그냥 쉬어갈 수 있어요.

03. 기억 수정과 삭제

‘보관함’에서 기억을 열고 글·사진·온기 종류를 수정하세요. 기억을 삭제하면 앱 내부에 복사한 사진도 정리돼요. 사진 보관함의 원본과 내보낸 백업 파일은 별도로 관리하세요.

04. 백업과 기기 이동

  1. ‘방 이야기’에서 ‘백업 내보내기’를 누르세요.
  2. 글과 사진을 포함한 JSON 파일을 직접 선택한 위치에 저장하세요.
  3. 다른 기기의 온기방에서 ‘백업 가져오기’로 해당 파일을 선택하세요.
  4. 파일 전체를 검증한 뒤 새 기억만 더해요. 같은 식별자의 기존 기억은 덮어쓰지 않아요.

백업 파일에는 개인 문장과 사진이 포함돼요. 파일 자체는 암호화하지 않으므로 안전한 위치에 보관하세요. 최대 크기는 200MB예요. 기억이 많은 경우 백업 오류가 발생하면 먼저 기억과 사진을 점검하고 고객 지원에 문의하세요. 앱을 삭제하거나 기기를 바꾸기 전에 필요한 기억을 반드시 백업하세요.

05. 그냥 쉬기

방에서 ‘그냥 쉬기’를 선택하면 약 1분 동안 온이와 조용히 머물 수 있어요. 소리는 기본적으로 없고 언제든 끝낼 수 있어요. 앱이 비활성 상태이면 쉼의 시간과 움직임도 멈춰요.

06. 편안한 움직임과 키보드

기기 설정의 손쉬운 사용에서 ‘동작 줄이기’를 켜면 온이가 반복해서 떠다니거나 사물로 이동하지 않아요. 대신 표정과 정적인 강조로 반응해요. Mac에서는 ⌘N으로 새 기억을 담고, Escape로 쉬기 화면에서 나올 수 있어요.

기억이 보이지 않을 때

위로 화면에는 해당 온기를 직접 지정한 기억만 나타나요. ‘보관만 하기’ 기억은 보관함에서 확인할 수 있어요. 다른 기기의 기억이 필요하다면 백업을 직접 가져와야 해요. 1.1에서는 자동 동기화를 사용하지 않아요.

사진이 열리지 않을 때

유효한 이미지 파일인지 확인하고 다시 선택해보세요. 가져오는 이미지의 최대 크기는 50MB이며, 앱에서 최대 2048px의 JPEG 사본으로 보관해요. 사진 보관함의 원본을 지워도 이미 저장한 사본은 유지돼요.
