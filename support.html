작은 방 사용 안내

처음 들어오는 날에도 편안하게.
온기방 1.1을 사용하는 방법을 모았어요.

처음 시작하기기억 저장과 수정사진 다루기백업하기기기 이동쉬기와 움직임문제 해결고객 지원
이전 버전에서 오셨나요?

1.1은 새로운 기억의 방입니다. 1.0의 오늘 기록·일정·집중 기능과 별개의 저장소를 사용하며, 이전 기록과 백업의 자동 변환을 지원하지 않습니다. 업데이트 전 필요한 이전 기록을 별도로 보관해주세요.

01 · 처음 들어오는 날

기록 없이 시작해도 괜찮아요.

앱을 열면 온이가 작은 방에서 반겨요. 회원가입이나 네트워크 연결 없이 사용할 수 있어요. 방의 온이를 누르거나 ‘그냥 쉬기’로 잠깐 머물러보세요.

  1. 기억을 남기고 싶을 때 ‘온기 담기’를 선택하세요.
  2. 짧은 문장 또는 사진 한 장을 담아주세요.
  3. 다시 꺼내볼 온기를 고르고 ‘기억 담아두기’를 누르세요.

기억을 작성하지 않아도 방과 ‘그냥 쉬기’를 사용할 수 있어요.

02 · 나에게서 온 온기

기억을 담고, 필요한 날 꺼내요.

글과 사진 중 하나만 있어도 저장할 수 있어요. ‘기억의 온기’ 기본값은 ‘보관만 하기’예요. 쉼·응원·연결을 직접 지정한 기억만 해당 온기 흐름에 나타나요.

쉬고 싶어 · 담요

편안했던 순간, 쉬어도 된다는 문장

응원이 필요해 · 스탠드

버텨낸 일, 다시 읽고 싶은 응원

연결감을 느끼고 싶어 · 머그잔

따뜻한 대화, 고마웠던 순간

방의 사물이나 온기 버튼을 누르면 해당 종류의 기억을 최근 저장 순으로 한 장씩 꺼내요. 기억이 없으면 새 기억을 담거나 그냥 쉬어갈 수 있어요.

수정과 삭제

‘보관함’에서 기억을 열고 글·사진·온기 종류를 수정한 뒤 ‘변경 저장하기’를 누르세요. 삭제하면 앱 내부에 복사한 사진도 정리돼요. 사진 보관함의 원본과 내보낸 백업 파일은 별도로 관리하세요.

03 · 사진 한 장

원본과 독립적으로 보관해요.

‘사진 고르기’ 또는 ‘파일에서 사진 고르기’로 사진 한 장을 선택하세요. 저장할 때 앱 내부에 사본을 만들기 때문에 원본을 지워도 저장된 기억의 사진은 유지돼요.

유효한 이미지 파일을 선택해주세요. 가져오는 이미지의 최대 크기는 50MB이며, 앱에는 긴 변 최대 2048px의 JPEG 사본으로 보관해요. 사진을 빼고 싶다면 편집 화면의 ‘사진 빼기’를 사용하세요.

04 · 나의 기억 지키기

사진까지, 하나의 백업으로.

  1. ‘방 이야기’에서 ‘백업 내보내기’를 누르세요.
  2. 글과 사진을 포함한 JSON 파일을 직접 선택한 위치에 저장하세요.
  3. 파일을 안전한 위치에 보관하고, 앱을 삭제하거나 기기를 바꾸기 전에 백업 여부를 확인하세요.
백업 파일도 개인 기록이에요.

백업 파일 자체는 암호화하지 않습니다. 공유할 위치와 접근 권한을 확인해주세요. 앱에서 기억을 삭제해도 이미 내보낸 백업 파일은 별도로 삭제해야 해요.

가져올 수 있는 백업 파일의 최대 크기는 200MB예요. 1.1의 백업 형식 버전은 1이며 이전 앱 버전의 백업을 자동 변환하지 않아요.

05 · 다른 기기로 옮기기

자동 동기화 대신, 직접 옮겨요.

  1. 기존 기기에서 ‘백업 내보내기’로 파일을 저장하세요.
  2. 직접 선택한 파일 전송 방법으로 다른 기기에 옮기세요.
  3. 다른 기기의 ‘방 이야기’에서 ‘백업 가져오기’를 누르고 파일을 선택하세요.

파일 전체를 검증한 뒤 새 기억만 추가해요. 같은 식별자의 기존 기억은 덮어쓰지 않아요. 다른 기기에서 수정한 내용이 자동으로 기존 기억에 반영되지는 않습니다.

06 · 오늘은 그냥 쉬기

1분의 쉼도, 충분해요.

‘그냥 쉬기’를 선택하면 약 1분 동안 온이와 조용히 머물 수 있어요. 소리 없이, 원할 때 ‘방으로 돌아가기’나 닫기 버튼으로 끝낼 수 있어요. 앱이 비활성 상태이면 쉼의 시간과 움직임이 멈춰요.

움직임과 키보드

기기의 손쉬운 사용 설정에서 ‘동작 줄이기’를 켜면 반복 부유와 사물 이동을 멈추고 정적인 표정·강조로 반응해요. Mac에서는 ⌘N으로 새 기억을 담고 Escape로 쉬기 화면에서 나올 수 있어요.

07 · 잘되지 않을 때

차근차근 확인해보세요.

위로 화면에 기억이 보이지 않아요.

해당 온기를 직접 지정한 기억만 나타나요. ‘보관만 하기’ 기억은 보관함에서 확인하고, 필요하다면 기억의 온기 종류를 바꿔주세요.

다른 기기의 기억이 보이지 않아요.

각 기기의 기록은 독립적으로 보관돼요. 다른 기기에서 내보낸 백업을 직접 가져와야 합니다. 기기 이동 순서를 확인해주세요.

사진을 선택하거나 저장할 수 없어요.

유효한 이미지인지, 50MB 이하인지 확인해주세요. 사진 보관함에서 선택되지 않으면 ‘파일에서 사진 고르기’도 사용할 수 있어요. 문제가 계속되면 기기와 앱 버전, 발생 순서를 알려주세요.

백업을 가져올 수 없어요.

온기방 1.1에서 내보낸 JSON 파일인지, 200MB 이하인지 확인해주세요. 손상되거나 지원하지 않는 파일은 가져오지 않아요. 파일을 직접 수정하지 말고 원래 기기에서 다시 내보내보세요.

앱을 삭제하거나 기기를 바꿔도 기록이 남나요?

로컬 기록은 운영체제의 앱 데이터 관리 방식에 따라 삭제될 수 있어요. 기기 백업이 항상 복원된다고 보장하지 않으므로, 필요한 기억을 직접 내보내 보관해주세요.
