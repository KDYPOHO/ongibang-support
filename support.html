처음 들어오는 날

지금의 나에게 필요한 곳부터.

처음 사용할 때 iCloud 사용 여부를 선택합니다. 기기에만 보관해도 주요 기능을 사용할 수 있으며 ‘설정’에서 나중에 바꿀 수 있어요. 별도 회원가입은 필요하지 않습니다.

오늘

선택한 날짜의 일정과 완료한 일, 하루 마무리

방

온이와 기억 꺼내보기, ‘그냥 쉬기’

보관함

기억 찾기·수정·삭제, 온기 종류 바꾸기

설정

iCloud, 이 기기의 알림, 백업과 앱 정보

iPhone에서는 하단 탭, iPad·Mac에서는 사이드바로 이동해요. 기기의 앱 언어 설정에 따라 한국어와 영어가 표시되며, 내가 작성한 글은 번역하지 않습니다. 기록이 없어도 방에서 쉴 수 있어요.

오늘의 작은 계획

필요한 만큼만 정리해요.

  1. ‘오늘’에서 날짜를 고르고 ‘일정 추가’ 또는 +를 누르세요.
  2. 제목과 날짜를 입력하세요. 시간·메모·반복·알림은 선택사항이에요.
  3. 저장한 일정을 완료하거나 완료를 취소할 수 있어요. 제목만 빠르게 입력하면 선택한 날짜에 추가됩니다.

반복은 없음·매일·평일·매주 같은 요일을 지원합니다. 완료 상태는 날짜별로 나눠요. 수정은 미완료 회차와 이후 일정에 적용되며 이미 완료한 제목은 당시 기록으로 남습니다. 반복 일정을 삭제하면 이후 반복은 멈추고 완료 이력은 유지됩니다.

지난 미완료 일정은 원래 날짜에 남으며 다음 날로 자동 이동하지 않아요. 날짜 선택, 검색, 예정·완료 필터로 찾아보세요.

알림은 기기별로

알림을 사용하려면 일정에 시각을 지정하고 권한을 허용해야 합니다. ‘설정’의 ‘일정 알림 받기’는 각 기기에서 따로 선택해요. 거절해도 일정 관리는 계속할 수 있어요. 반복 알림은 가까운 회차부터 최대 60개를 예약하고 앱을 열거나 일정을 바꿀 때 보충합니다.

하루를 마친 나에게

마친 일보다, 마친 나를 돌아봐요.

‘오늘 마무리하기’에서 완료한 일을 돌아보고 오늘의 기분과 한 문장을 선택적으로 남겨요. 아무것도 완료하지 않은 날도 사용할 수 있어요. ‘기록 없이 쉬기’로 바로 온이 곁에 머물 수도 있습니다.

‘하루 기록 보기’에서 날짜별로 조회·수정·삭제합니다. 회고는 일정과 분리되어 일정을 지워도 남아요. ‘기억으로 담기’를 직접 선택해야 보관함에 문장이 추가되며 기본 온기는 ‘보관만 하기’입니다.

02 · 나에게서 온 온기

기억을 담고, 필요한 날 꺼내요.

글과 사진 중 하나만 있어도 저장할 수 있어요. ‘기억의 온기’ 기본값은 ‘보관만 하기’예요. 쉼·응원·연결을 직접 지정한 기억만 해당 온기 흐름에 나타나요.

쉬고 싶어 · 담요

편안했던 순간, 쉬어도 된다는 문장

응원이 필요해 · 스탠드

버텨낸 일, 다시 읽고 싶은 응원

연결감을 느끼고 싶어 · 머그잔

따뜻한 대화, 고마웠던 순간

방의 사물이나 온기 버튼을 누르면 해당 종류의 기억을 최근 저장 순으로 한 장씩 꺼내요. 기억이 없으면 새 기억을 담거나 그냥 쉬어갈 수 있어요.

수정과 삭제

‘보관함’에서 기억을 열고 글·사진·온기 종류를 수정한 뒤 ‘변경 저장하기’를 누르세요. 삭제하면 앱 내부에 복사한 사진도 정리돼요. 사진 보관함의 원본과 내보낸 백업 파일은 별도로 관리하세요.

03 · 사진 한 장

원본과 독립적으로 보관해요.

‘사진 고르기’ 또는 ‘파일에서 사진 고르기’로 사진 한 장을 선택하세요. 저장할 때 앱 내부에 사본을 만들기 때문에 원본을 지워도 저장된 기억의 사진은 유지돼요.

유효한 이미지 파일을 선택해주세요. 가져오는 이미지의 최대 크기는 50MB이며, 앱에는 긴 변 최대 2048px의 JPEG 사본으로 보관해요. 사진을 빼고 싶다면 편집 화면의 ‘사진 빼기’를 사용하세요.

04 · 나의 기억 지키기

사진까지, 하나의 백업으로.

  1. ‘설정’에서 ‘백업 내보내기’를 누르세요.
  2. 글과 사진을 포함한 JSON 파일을 직접 선택한 위치에 저장하세요.
  3. 파일을 안전한 위치에 보관하고, 앱을 삭제하거나 기기를 바꾸기 전에 백업 여부를 확인하세요.
백업 파일도 개인 기록이에요.

백업 파일 자체는 암호화하지 않습니다. 공유할 위치와 접근 권한을 확인해주세요. 앱에서 기억을 삭제해도 이미 내보낸 백업 파일은 별도로 삭제해야 해요.

가져올 수 있는 백업 파일의 최대 크기는 200MB예요. 1.3은 형식 2로 기억·사진·일정·완료 상태·하루 기록을 내보내며 1.1의 형식 1도 가져올 수 있어요. 파일 전체를 검증한 뒤 새 식별자만 추가하고 기존 기록과 삭제 이력을 덮어쓰지 않습니다. 1.0 백업은 자동 변환하지 않아요.

나의 기기끼리

연결할지, 직접 옮길지 선택해요.

1.3 · 선택형 iCloud

  1. 각 기기에 같은 Apple 계정으로 로그인되어 있는지 확인하세요.
  2. 온기방의 ‘설정’에서 ‘나의 기기끼리 동기화’를 켜세요.
  3. 전송 대기와 최근 동기화를 확인하세요. 즉시 반영되지 않을 수 있습니다.

기억·사진·일정·완료 상태·하루 기록을 Apple CloudKit 비공개 데이터베이스에서 동기화합니다. 오프라인 수정은 먼저 기기에 남아요. 다시 연결한 뒤 전송 대기가 남으면 ‘동기화 다시 시도’를 누르세요.

동기화를 꺼도 기기와 기존 iCloud 기록은 남습니다. Apple 계정이 바뀌면 멈추며 새 계정에 이전 기록을 자동 전송하지 않아요. 알림 수신 여부는 동기화하지 않고 기기마다 선택합니다.

백업으로 직접 옮기기 · 1.1에서도 가능

기존 기기에서 ‘백업 내보내기’로 만든 JSON 파일을 다른 기기로 옮기고 ‘백업 가져오기’를 선택하세요. 1.3에서는 ‘설정’, 1.1에서는 ‘방 이야기’에 있어요. 같은 식별자의 기존 기록을 덮어쓰지 않습니다.

06 · 오늘은 그냥 쉬기

1분의 쉼도, 충분해요.

‘그냥 쉬기’를 선택하면 약 1분 동안 온이와 조용히 머물 수 있어요. 소리 없이, 원할 때 ‘방으로 돌아가기’나 닫기 버튼으로 끝낼 수 있어요. 앱이 비활성 상태이면 쉼의 시간과 움직임이 멈춰요.

움직임과 키보드

기기의 손쉬운 사용 설정에서 ‘동작 줄이기’를 켜면 반복 부유와 사물 이동을 멈추고 정적인 표정·강조로 반응해요. Mac에서는 ⌘N으로 현재 화면의 새 일정이나 기억을 작성하고 Escape로 쉬기 화면에서 나올 수 있어요.

07 · 잘되지 않을 때

차근차근 확인해보세요.

위로 화면에 기억이 보이지 않아요.

해당 온기를 직접 지정한 기억만 나타나요. ‘보관만 하기’ 기억은 보관함에서 확인하고, 필요하다면 기억의 온기 종류를 바꿔주세요.

다른 기기의 기억이 보이지 않아요.

1.3에서는 같은 Apple 계정인지, 각 기기의 동기화 설정·네트워크·iCloud 저장 공간을 확인하세요. 두 기기에서 앱을 열고 ‘동기화 다시 시도’를 눌러보세요. 재연결 후 전송이 늦거나 최초 수신 오류가 보이면 다시 시도하고, 계속되면 지원에 알려주세요. 현재 출시된 1.1에서는 백업을 직접 가져와야 합니다. 기기 이동 순서를 확인해주세요.

사진을 선택하거나 저장할 수 없어요.

유효한 이미지인지, 50MB 이하인지 확인해주세요. 사진 보관함에서 선택되지 않으면 ‘파일에서 사진 고르기’도 사용할 수 있어요. 문제가 계속되면 기기와 앱 버전, 발생 순서를 알려주세요.

백업을 가져올 수 없어요.

온기방 1.1 또는 1.3에서 내보낸 형식 1·2 JSON 파일인지, 200MB 이하인지 확인해주세요. 손상되거나 지원하지 않는 파일은 가져오지 않아요. 파일을 직접 수정하지 말고 원래 기기에서 다시 내보내보세요.

앱을 삭제하거나 기기를 바꿔도 기록이 남나요?

로컬 기록은 운영체제의 앱 데이터 관리 방식에 따라 삭제될 수 있어요. 기기 백업이 항상 복원된다고 보장하지 않으므로, 필요한 기억을 직접 내보내 보관해주세요.
