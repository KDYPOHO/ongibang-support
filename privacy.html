개인정보 처리방침

적용 버전: 온기방 1.1 · 시행일: 2026년 10월 8일
운영자: 강동엽 · 문의: todaklife@gmail.com

이 안내는 온기방 1.1의 기억의 방에 적용됩니다. 1.0의 오늘 기록·일정·집중 기능을 사용하는 경우 이전 버전의 개인정보 처리방침을 확인해주세요.

1. 기기에 보관하는 기록

온기방 1.1은 회원가입, 서버 전송, 광고, 추적 또는 사용 분석을 사용하지 않습니다. 작성한 글, 직접 지정한 온기 종류와 선택한 사진은 앱의 로컬 저장 공간에 보관합니다. 개발자는 이 기록에 접근하지 않습니다. 앱 기록을 제3자에게 판매하거나 제공하지 않습니다.

2. 직접 선택한 사진

사진 보관함 또는 파일 선택 화면에서 사용자가 직접 선택한 사진만 앱 내부에 복사합니다. 복사한 사진은 최대 2048px JPEG 사본으로 보관하며 사진 보관함의 원본과 독립적으로 유지됩니다.

3. 수정과 삭제

보관함에서 기억을 수정하거나 삭제할 수 있습니다. 기억을 삭제하면 연결된 앱 내부 사진 사본도 정리합니다. 앱을 삭제하면 기기와 운영체제의 앱 데이터 관리 방식에 따라 로컬 기록이 삭제됩니다. 재설치나 기기 이동 전에 필요한 기록을 백업해주세요.

4. 직접 내보내는 백업

백업 내보내기는 글과 사진을 포함한 JSON 파일을 사용자가 직접 선택한 위치에 저장합니다. 백업 파일 자체는 암호화하지 않습니다. iCloud Drive 등 외부 저장 서비스를 선택하면 해당 서비스의 개인정보 정책이 적용됩니다. 앱에서 기억을 지워도 내보낸 백업은 별도로 삭제해야 합니다. 가져오기는 파일 검증 후 새 식별자의 기록만 추가하며 기존 기록은 덮어쓰지 않습니다.

5. 운영체제의 백업

운영체제의 기기 백업 설정에 따라 앱 데이터가 기기 백업에 포함될 수 있습니다. 온기방 1.1 자체의 자동 동기화 기능은 없습니다.

6. 고객 지원 이메일

고객 지원 또는 개인정보 문의: todaklife@gmail.com. 사용자가 문의 이메일에 직접 포함한 연락처와 문의 내용은 문의 확인 및 답변을 위해 사용됩니다. 개인 기억이나 사진을 보내실 필요는 없습니다. 이메일 서비스의 개인정보 정책도 적용됩니다. 문의 내용 삭제를 원하면 같은 주소로 요청해주세요.

7. 홈페이지

이 홈페이지는 GitHub Pages에서 제공하는 정적 웹사이트입니다. 별도의 광고·분석 스크립트, 회원가입, 방문자 정보 입력 폼을 사용하지 않습니다. 호스팅 제공자인 GitHub의 서비스 운영 과정에는 GitHub 개인정보 정책이 적용됩니다.

8. 변경 안내

기능이나 데이터 처리 방식이 변경되면 이 페이지에 적용 버전과 시행일을 함께 안내합니다.
